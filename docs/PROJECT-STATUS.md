## How to work on it

- **Run it locally:** double-click `run-local.bat`. It opens the server and client windows and the browser at `localhost:5173`.
- **Upload changes:** double-click `update.bat` (or ask Claude). Vercel and Render redeploy about two minutes later.
- **Before finishing any change:** `cd client && npx vite build` must pass.
